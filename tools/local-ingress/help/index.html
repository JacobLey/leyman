Routes https://<worktree>.<repo>.localhost to each worktree's devcontainer, with certificates from a certificate authority (CA) created on this machine. Trust that CA once, and every worktree of every repo loads without a warning.

Trust the CA

Download the root certificate, then add it to your system's trust store, or from a terminal:

curl -fsSo local-ingress-root.crt http://ingress.localhost/root.crt

macOS

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain local-ingress-root.crt

Linux (Debian, Ubuntu)

sudo cp local-ingress-root.crt /usr/local/share/ca-certificates/local-ingress-root.crt
sudo update-ca-certificates

Chrome and Chromium on Linux keep their own store: Settings → Privacy and security → Security → Manage certificates → Authorities → Import.

Windows (an administrator prompt)

certutil -addstore -f ROOT local-ingress-root.crt

Firefox

Firefox keeps its own store. Either import the certificate (Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, then tick "Trust this CA to identify websites"), or have it trust the system's store by setting security.enterprise_roots.enabled to true in about:config.

Restart the browser afterwards. The root never needs replacing: it lives as long as the ingress's data volume.

local-ingress version {{env "LOCAL_INGRESS_VERSION"}}
