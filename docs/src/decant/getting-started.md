# Getting started

## Install

::: code-group

```sh [npm]
npm i -D decant
```

```sh [pnpm]
pnpm add -D decant
```

```sh [yarn]
yarn add -D decant
```

:::

::: tip
decant requires Node.js 24 or later. Its output is plain TypeScript, so it is a dev dependency only.
:::

## Generate types

```sh
npx decant schemas/user.json --name User
```

decant writes `schemas/user.ts` next to the schema (or `-o` to choose the path), and prints the file it wrote:

- The root schema becomes the type named by `--name` (`Schema` by default).
- Every definition in the root `$defs` (or draft 7 `definitions`) becomes an exported type named after its key, in PascalCase, whether or not it is referenced.
- A schema referenced by `$ref` from anywhere else in the document becomes a named type too, named after its key in any nested `$defs`, or else after its path. Everything else is inlined.

```ts
// Generated by decant. Do not edit by hand, regenerate it instead.

export type User = {
    id: `usr_${string}`;
    home?: Address;
};

export type Address = {
    city: string;
};
```

The file is formatted with your project's Biome or Prettier config, if either is installed.

If the schema has a mistake, such as a misspelled keyword, decant fails with a JSON Pointer to it instead of writing a looser type. See [Strict mode](/decant/guides/strict-mode).

## Check types in CI

Commit the generated file, and check it is up to date in CI:

```sh
npx decant schemas/user.json --name User --ci
```

`--ci` generates the types without writing, and fails if the file would change. It is on by default when decant detects CI (with [ci-info](https://www.npmjs.com/package/ci-info)), so the same command writes locally and checks in CI.

In an Nx workspace, a cached target per schema does that before compiling:

```json
// project.json
{
    "targets": {
        "decant": {
            "executor": "nx:run-commands",
            "options": {
                "command": "decant schemas/user.json --name User",
                "cwd": "{projectRoot}"
            },
            "cache": true,
            "inputs": ["{projectRoot}/schemas/user.json"],
            "outputs": ["{projectRoot}/schemas/user.ts"]
        }
    }
}
```
