# eslint-config

This package contains a shared eslint-config for re-use internally across leyman packages.

It is not published publicly, because the rule set is hyper-opinionated and would often include changes that could be considered breaking.

However users are welcome to directly reference or copy this code if they wish to emulate similar eslint rules in their packages.

## Changesets

Don't write a changeset for this package.
It is never published, so a version bump (and the `CHANGELOG.md` that `changeset version` would write for it) describes nothing anyone installs.
When a rule change makes a package change its code, that package's own changeset describes it.
